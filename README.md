# ShopEase – Manual Testing Project

## Project Overview

ShopEase is a fictional e-commerce application used as a portfolio case study to demonstrate fundamental Software Quality Assurance (SQA) and manual testing skills.

This project focuses on documenting test requirements, designing test cases, preparing test plans, and organizing defect reports for the login functionality.

## Project Objectives

* Practice requirement analysis and test case design.
* Create structured manual testing documentation.
* Understand positive and negative testing.
* Maintain traceability between requirements and test cases.
* Learn defect reporting and test execution reporting.

## Project Scope

The current scope covers:

* Login with valid credentials
* Login with an incorrect password
* Empty required fields
* Invalid email format
* Login with an unregistered email
* Password visibility, if available
* Forgot Password navigation, if available
* Sign Up navigation, if available

## Project Deliverables

* Requirements documentation
* 10 manual test cases
* Bug report template
* Test Plan
* Test Execution Report

## Tools Used

* Google Sheets

* GitHub

## Current Project Status

**Status:** Test documentation prepared; execution not started.

The requirements and expected behaviours are assumptions defined for this fictional case study. A working application or mock test environment has not yet been established. Therefore, no test cases have been executed and no defects have been confirmed.

## Future Improvements

* Establish a working test environment.
* Execute the documented test cases.
* Record actual results and execution status.
* Document any confirmed defects.
* Expand testing to registration, product search, cart, and checkout.

## Disclaimer

ShopEase is a fictional portfolio project created for learning and demonstration purposes. It is not a report of testing performed on a live e-commerce application.
